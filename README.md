## 🚀 Featured projects

### 🧬 [CADS: Credential-Agnostic Data Sovereignty](https://github.com/Tejaswiny-k12/CADS-demo)
A zero-trust, data-centric security framework for IoMT. The security boundary is the data packet itself, not user credentials or the network perimeter. Built with teammates **Ranjhani B** and **Madhumitha M**.

- Six algorithms: **DBI** (device-bound identity), **C-TTL** (cryptographic TTL), **BCE** (behavioral contract engine), **PoPC** (proof-of-path chain), **CSM** (cryptographic state machine), **MBA** (mutual behavioral attestation)
- Two-gate pipeline: Gate 1 verifies identity and packet integrity; Gate 2 runs challenge-response auth, ECDH session setup and MBA
- Crypto: ECDSA P-256, ECDH, HKDF-SHA256, AES-256-GCM
- Live SOC dashboard (Streamlit) with a signature-only baseline comparison and a deterministic attack simulator (tamper, replay, bad signature, anomaly)
- Validated in simulation so far; ESP32 hardware integration is in progress

### 🍯 [Honey-80: Docker honeypot](https://github.com/Tejaswiny-k12/Honey-80)
A fake, deliberately vulnerable chatbot (Flask) that drops attackers into an isolated Ubuntu Docker container, then logs every command, IP and user ID. Includes alerting and an IDS API.
